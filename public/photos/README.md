## 행사별 TourAPI 사진

`src/lib/festival-photo-manifest.json`에는 2026-10-01에 수집된 한국관광공사 TourAPI 행사 목록 스냅샷(`/tmp/gotgot-festivals-oct01.json`)과 `contentid`가 정확히 일치하는 행사 사진 18개의 직접 주소가 있다. 각 항목은 TourAPI의 `firstimage`, `cpyrhtDivCd: Type3` 정보와 행사 ID를 함께 대조했다. 화면에는 사진 출처를 표시하며, 공식 이미지 서버가 응답하지 않으면 프로젝트의 분류 그래픽 또는 위 지역 대표 사진으로 자동 전환한다.

현재 실행 환경에서는 한국관광공사 이미지 서버 연결이 HTTP 403으로 차단되어 18개 원본 파일을 직접 내려받거나 육안으로 재확인하지 못했다. 공개 배포 전에는 직접 주소의 응답, 사진 내용, 최신 이용 조건을 다시 확인해야 한다.

## 카테고리 대표 이미지

`categories/`의 WebP 파일 14장은 2026-10-29에 OpenAI 이미지 생성 도구로 이 프로젝트를 위해 제작했다. 문화·예술부터 웰니스·휴식까지 모든 활동 카테고리에 서로 다른 이미지를 연결한다. 1536×1024 원본은 `/workspace/generated_images`에 보존하고, 웹에는 로딩 속도를 위해 960×640 WebP 파일을 사용한다.

이 이미지는 특정 장소나 실제 행사 현장을 촬영한 사진이 아니다. 장소별로 확인된 사진이 없는 카드에만 `카테고리 대표 이미지 · AI 생성`이라고 표시한다. 장소별 한국관광공사 사진이 있으면 해당 사진을 우선하며, 외부 사진 서버가 응답하지 않을 때도 카테고리 대표 이미지로 전환한다. 세부 파일과 용도는 [`categories/README.md`](./categories/README.md)에 기록했다.
