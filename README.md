# 곳곳 — 전국 지역활동 웹

실제 웹 실행과 현재 제한은 [웹 실행 안내](docs/WEB_SETUP.md)를 먼저 읽으세요. 기존 보일러플레이트 안내는 [docs/SETUP.md](docs/SETUP.md)에 있습니다.

**Express 회원가입·로그인·세션 유지와 현장 GPS 적립은 실제로 동작합니다. AI·실제 제휴 쿠폰의 운영 데이터는 Supabase와 AI 서비스 연결 후 별도로 검증해야 합니다.**

## 프로젝트 개요
- 한 줄 소개: 전국의 문화·스포츠·여가를 발견하고 참여를 지역 혜택으로 연결하는 웹.
- 누구를 위한 앱인가: 지역 주민과 전국을 여행하는 모든 사용자.
- 어떤 상황에서 쓰는가: 내 취향에 맞는 활동과 낯선 지역의 이야기를 찾을 때. PC·모바일 브라우저를 지원합니다.

## 주요 기능
| 과제의 꼭 있어야 하는 기능 | 화면(프론트엔드) | API(백엔드) |
| --- | --- | --- |
| 1. 곳곳드림 | GPS 현장 인증·혜택 목록·교환 확인·직원확인 쿠폰 화면 | Express 거리/정확도 검증·중복 적립 방지, Supabase 원자적 교환·1회 사용 코드 |
| 2. AI 맞춤형 지역활동 추천 | 지역·관심사·예산·선택적 성별 반영 | 실제 후보 기반 AI·시간/횟수 제한·출력 검증 코드. 실제 호출 미검증 |
| 3. 지역을 설명해주는 지도 | 17개 시도 소개·선택·활동 연결 | 공개 활동 목록/단건 API. 현재 예시 데이터·개략도 |

더 만든 기능: 검색·14개 분야 필터·활동 상세. 독도를 포함한 공개 지역·참여 안내 518개와 공식 확인 링크를 제공하며 모든 분야에 전국 기준 최소 4개가 있습니다. 활동 둘러보기와 곳곳드림에서 좌표가 있는 대상 장소의 GPS 방문을 인증하면 식당 100P·축제 300P·자연·생태 200P·역사·전통 및 가족·키즈 150P를 한 번 적립하고 MY 방문 기록과 원장에 연결합니다. 축제는 등록된 행사 기간에만 인증합니다. 유기견 보호센터는 봉사·커뮤니티에서 안내하며 자동 적립하지 않습니다.

## 기술 스택
- 프론트엔드: Next.js 16.4.3 App Router, React 19, TypeScript, 반응형 CSS, 자체 제공 한글 폰트.
- 백엔드: Node.js, Express 5, Next.js Route Handler, 서버 입력 검증.
- 로그인 데이터: 기본값 `data/auth-store.json`. 비밀번호는 개별 salt를 적용한 scrypt 해시, 세션은 SHA-256 해시만 저장합니다.
- 서비스 데이터: Express JSON 저장소에서 GPS 방문·마일리지 원장을 검증했습니다. Supabase PostgreSQL용 프로필·활동·저장·쿠폰·마일리지·AI RLS는 준비했으며 실제 프로젝트에는 미연결입니다.

## 실행 방법
<!-- 처음 보는 사람이 그대로 따라 할 수 있게 쓴다. 시작 저장소 그대로라면: npm install → npm run dev → 브라우저에서 http://localhost:3000 -->
1. Node.js 24 준비 후 `npm ci`.
2. `npm run dev`를 실행합니다. Express와 Next.js가 함께 `http://localhost:3000`에서 열립니다.
3. 회원가입 후 로그인 상태는 7일 세션 쿠키로 유지됩니다. 인증 저장 경로 등은 [Express 인증 안내](docs/EXPRESS_AUTH.md)를 참고하세요.
4. 화면 파일만 보려면 `node scripts/build-web-preview.mjs`를 실행합니다. 단일 HTML 미리보기에는 실제 로그인이 없습니다.

화면 미리보기: https://millo981229-spec.github.io/pep/ — 정적 GitHub Pages이므로 로그인·영구 GPS 적립은 Node 서버 실행본에서 확인합니다.

현재 실제 제휴처·Supabase·AI 연결, 운영자 스캔 UI, 쿠폰 취소·환불, 회원 복구·탈퇴, 로그인 후 Lighthouse 측정이 남아 있습니다. GPS 인증은 식당 반경 100m·오차 50m 이하, 그 외 대상 장소 반경 250m·오차 100m 이하·5분 이내 측정값을 서버가 다시 확인하며 같은 장소는 한 번만 적립합니다. 실제 운영에서는 GPS 조작 방지를 위해 현장 QR 또는 직원 확인을 함께 적용해야 합니다.
