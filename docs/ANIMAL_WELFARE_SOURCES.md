# 유기견 보호·입양·봉사 안내의 확인 범위

2026-10-30 KST. `봉사·커뮤니티`에서 유기견 보호·입양·봉사 정보를 찾을 수 있도록 공개 과거 자료에서 기관명과 소재 지역을 대조한 서울·부산·대구·인천·광주·대전·울산·창원 8곳을 추가한다. 현재 운영 여부와 참여 조건을 확인한 봉사 모집 공고는 아니다. 센터에 임의 방문하거나 봉사 접수·입양을 완료하는 서비스는 제공하지 않는다.

보호센터의 관할 지역과 실제 소재지는 다를 수 있다. 예를 들어 과거 자료에서 인천 연수구를 관할하던 시설은 계양구에 있었고, 울산 중구를 관할하던 시설은 울주군에 있었다. 따라서 목록의 `area`를 시설 소재지로 그대로 사용하지 않고 `address`를 함께 대조했다.

처음 후보로 고려했던 세종·수원·용인은 확보한 과거 자료에서 해당 센터명·주소를 대조하지 못했으므로 이번 추가에서 제외했다. 부산은 대조하지 못한 일반명 `부산동물보호센터` 대신 실제 목록에 수록된 `유기동물보호관리협회`로 정리하고 화면에는 보호센터 안내임을 함께 표시한다.

## 읽은 원본

- [서울 보호센터 공개 CSV 고정 스냅샷](https://github.com/fora22/Animal-Shelter/blob/8f08bfe58182a59122352f38675d96b5e9058a62/Next_Level/kangyejee/%EB%8F%99%EB%AC%BC%EB%B3%B4%ED%98%B8%EC%84%BC%ED%84%B0.csv): 서울 관할 55행. 서울동물복지지원센터와 마포 소재 주소를 대조했다. 이 자료에는 다른 9개 도시 자료가 없다.
- [전국 보호센터 공개 CSV 고정 스냅샷](https://github.com/SINAEEE/BigdataProject_AbandonedAnimal/blob/68c80754c91a21e77e437949b91bbcadde2c312c/__result__/crawling/shelter.csv): 2018년 프로젝트에 보존된 과거 자료다. 652행은 같은 326개 기록이 두 번 포함된 구조이며, 여러 지자체가 같은 시설을 이용하는 중복도 있다. 이 자료에서 부산·대구·인천·광주·대전·울산·창원의 명칭과 실제 소재 지역을 대조했다.

CSV의 기관 전화번호·담당자 정보는 앱에 복사하지 않았다. 원자료는 현재의 시설명·위탁·이전·개방·입양 가능 동물을 보증하지 않는다. 대전처럼 과거 주소를 현재 주소로 오인할 수 있으므로 앱의 주 주소는 지역과 기관명으로 제시하고, 수집 당시 상세 주소는 해당 사실을 명시한 안내문 안에만 둔다. 네이버 검색에는 지역과 기관명을 사용하며 임의 도로번호·좌표·전화번호·네이버 place ID를 만들지 않았다.

## 최신 정보와 네이버 지도 확인의 한계

공식 사이트와 네이버 지도는 현재 환경의 네트워크 정책으로 직접 대조하지 못했다. [국가동물보호정보시스템의 보호센터 안내](https://www.animal.go.kr/front/awtis/institution/institutionList.do)와 지자체·기관 사이트를 최신 정보를 확인할 경로로 제공한다. 이들 링크를 읽어 최신 운영을 확인한 것처럼 표현하지 않는다.

8곳 모두 `reference.verification=link-only`, 확인일 빈 값, `location.verification=locality-query`, `naverVerifiedAt=null`로 기록한다. 과거 CSV 대조와 현재 공식 원문·네이버 확인을 구분한다. 요금은 미확인 값 `null`이며 영업 중·모집 중·무료라고 표시하지 않는다. 사진은 기존 봉사·커뮤니티 카테고리 대표 이미지로, 실제 센터·보호 동물을 촬영한 사진이라고 표시하지 않는다.

## 예약과 마일리지

8개 항목 모두 `reference.participationType=contact-required`, `reward=0`이다. 방문·입양 상담·봉사는 센터에 따라 사전예약, 안전교육, 연령·정원 조건이 있을 수 있으므로 신청·방문 전에 공식 안내를 확인하게 한다.

보호소에 가까이 가거나 입양·봉사를 했다는 이유로 포인트를 자동 지급하지 않는다. GPS 적립 허용 목록에도 넣지 않는다. 봉사 실적을 실제 마일리지로 연결하려면 기관 협약·활동 확인·개인정보 처리·적립 정책을 먼저 정해야 한다. 심사를 위해 존재하지 않는 봉사 접수나 보호소 자동 적립 성공 화면을 만들지 않는다.
