## 사진

한국관광공사 관광사진으로 기록된 부여·상주·서귀포·진주 사진 4장을 홈 배너와 지역 사진 모음에 적용했다. 특정 행사·시설 사진이라고 단정하지 않고 `지역 대표 사진`과 크레딧을 표시한다. 여기에 TourAPI 행사 ID와 정확히 연결되는 행사 사진 주소 18개를 카드와 상세 화면에 적용했다. 공식 이미지 서버가 응답하지 않으면 해당 활동 분야의 카테고리 대표 이미지로 자동 전환한다. 따라서 현재 화면에는 항상 보이는 지역 실사 4장과, 서버 접근 가능 여부에 따라 표시되는 행사 실사 18장이 있다. 파일별 기록과 공개 전 재확인 항목은 [`public/photos/README.md`](../public/photos/README.md)에 있다.

실제 장소 사진이 없는 카드도 일러스트 대신 활동 분야에 맞는 카테고리 대표 이미지를 보여 준다. 14개 활동 분류마다 서로 다른 이미지를 OpenAI 이미지 생성 도구로 제작했으며 화면에 `카테고리 대표 이미지 · AI 생성`을 명시한다. 외부 행사 사진을 불러오지 못했을 때도 같은 카테고리 대표 이미지로 전환하므로 깨진 사진이 남지 않는다.

외부 관광·구단 사이트는 이 환경의 네트워크 정책으로 차단되어 있다. 접근 가능한 GitHub 공개 자료를 사용했으며 이를 공식 사이트에서 직접 검증한 결과로 표현하지 않는다. 확인 링크만 넣은 항목은 화면에도 **최신 일정 미확인**으로 표시한다. 공개 자료를 읽은 날짜와 원 자료 작성·수집일은 서로 다르게 보존한다.

## 지역 범위

기존 17개 지역의 축제·스포츠·음식점은 지역별 7개다(축제 3개, 스포츠·음식점 각각 2개). 경북에는 명소 44개와 독도 안내 1개가 있고, 추가 활동 안내 40개는 실제 기관 소재지에 따라 분류했다. 경북에서 명소 추가 전 정보가 없었던 안동·구미·영주·영천·문경·경산·의성·영양·영덕·청도·고령·성주·칠곡·예천·봉화·울릉을 모두 채웠다.

지역 이름은 서비스의 탐색 구분이며 최신 법정 행정구역 수를 보증하는 목록이 아니다. 수집본의 `전남광주통합특별시` 주소는 원문을 보존하면서 광주/전남 탐색 지역에 나눴다. 인천의 제물포구·영종구·검단구를 선택 목록에 반영했다. 기존 음식점 원 자료의 주소는 수집 당시 표기이므로 실제 위치 확인 링크를 제공한다.

## 저장·화면 연결

- 원본 편집 파일: `src/lib/regional-catalog.json`. ID·카테고리·소지역·자료 확인 상태·출처 URL·기간을 함께 저장한다.
- 서버 `/api/catalog`는 전체 자료에 지역·소지역·분류·검색어 조건을 먼저 적용하고 24개씩 반환한다. `hasMore`는 한 개를 추가 조회해 판단한다. 서버에 등록된 실제 활동도 같은 필터를 적용한다.
- 처음 불러온 페이지에 없던 제주 음식점도 검색된다. 조건 변경 시 이전 요청을 취소하고 늦은 응답이 새 결과를 덮지 못하게 한다.
- PC 지도에서도 소지역을 고를 수 있다. 상세 화면에 일정·주소·자료 상태·출처·지도/방문 정보 링크가 나온다. 종료된 일정은 종료로 표시하고, 미확인 가격은 `null`로 보존해 **가격 확인 필요**로 표시한다.
- 이 카탈로그는 공개 방문 정보다. 공개 좌표가 확인되어 `src/lib/checkin-places.json`에 명시된 행사·경기 35개만 해당 기간에 GPS 포인트 인증 대상으로 사용한다. 나머지는 예약·제휴 쿠폰·포인트 적립 대상으로 취급하지 않는다. 이 카탈로그를 추가했다고 AI에 자동 반영되지는 않는다.
- 공개 정보는 저장소에 포함되어 새로고침해도 다시 읽을 수 있다. 운영 DB에는 삽입하지 않았다. `is_demo=false`와 `reference` 필드로 허구 예시와 구분한다.

## 검증

`node scripts/verify-catalog.mjs`는 실행 중인 웹 서버에서 17개 지역의 축제 3개·스포츠/음식점 2개, 14개 분류의 최소 2개 안내, 유효한 소지역과 이미지 이름, 경북 22개 시·군의 명소 최소 2개, 전체 카탈로그 페이지 순회와 중복·누락, 첫 페이지 밖 검색, 소지역 필터, 상세 다시 읽기, 잘못된 입력 차단을 검사한다. 실제 DB가 연결되지 않은 카탈로그 환경을 기준으로 한다.

`scripts/verify-ui.mjs`는 390px/1280px에서 소지역·카테고리 선택, 출처 표시, 가격 표시, 상위 지역 변경 시 소지역 초기화, 지도 소지역 선택, 기존 관심사·바코드 미리보기를 확인한다. 안동·영양·울릉 명소와 주소·장소 기반 지도 링크도 확인한다. 영양군 스포츠 목록이 비었을 때 ‘이 지역의 다른 활동 보기’를 누르면 선택한 시·군을 유지하고 다른 분류의 명소를 볼 수 있다. 사진은 `docs/evidence/regional-catalog/`에 저장된다.

진행 중: 공식 정보 제공처 접속 허용 및 TourAPI 키 연결, 일정·폐업 확인과 주기적 갱신, 미확인 스포츠 안내 20개를 공식 확정 경기로 교체. 현재 정적 스냅샷이 실시간 현황인 것처럼 안내하지 않는다.
