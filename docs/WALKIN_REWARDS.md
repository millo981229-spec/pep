# 예약 없는 방문 인증과 보호센터 안내

2026-10-30 KST. 심사에 필요한 로그인·마일리지·AI 추천·지역 지도는 유지하며 예약·참가 등록을 구현한 것처럼 보이던 GPS 적립 경로를 정리했다.

## 적립 범위

곳곳드림과 활동 둘러보기는 `src/lib/checkin-policy.js`의 같은 GPS 정책을 사용한다. 기존 좌표가 있는 식당·축제·명소와 공공 산책 장소가 대상이며, 좌표가 없거나 위치가 충돌하는 자료, 예시 콘텐츠, 상담·예약 필수 또는 참여 조건이 명시적으로 미확인인 자료는 제외한다. 스포츠 대회의 참가 인증은 제공하지 않는다. 행사 종료일을 늘리거나 상시 운영으로 바꾸지 않는다.

적립액은 식당 100P, 축제 300P, 자연·생태 200P, 역사·전통·여행·관광·가족·키즈 150P다. 현재 좌표가 있는 후보는 308개이며 행사 기간에 따라 인증 가능 목록은 달라진다. 같은 좌표의 산책 장소와 축제도 동일 장소로 묶어 한 번만 적립하고 MY 방문 기록과 원장을 함께 저장한다. 기존 기록도 장소 ID로 대조한다. 최신 영업·개방·기상·행사 통제는 방문 전에 확인해야 한다. GPS는 장소 주변 방문을 확인하며 결제·유료 시설 입장·행사 참가·봉사 완료를 증명하지 않는다.

좌표는 기존 한국관광공사 TourAPI 공개 수집본의 실제 장소 대표점과 연결했다. 세종중앙공원은 여러 공원을 열거한 한글축제 대신 `contentid 3300114`의 중앙공원로 60 좌표를 사용했다. 원자료 URL은 각 활동과 `src/lib/checkin-places.json`에 남긴다. 네이버 지도 직접 대조와 최신 개방 확인은 환경의 접속 제한으로 미완료다.

서버는 정책에서 결정한 `walk-in` 또는 `location-visit` 장소만 허용한다. 클라이언트가 보낸 정책·보상액·다른 사용자 ID는 신뢰하지 않는다. 로그인 확인, 식당 반경 100m·오차 50m 이하/그 외 반경 250m·오차 100m 이하, 5분 이내 측정, 15분 8회 제한, 중복 적립 차단을 유지한다. 축제는 한국 시간 기준 시작일부터 종료일까지만 인증한다. 사용자 위치의 위도·경도를 저장하지 않으며 장소 ID·거리·정확도만 보관한다.

브라우저 GPS는 사용자가 위조할 수 있다. 따라서 이 구성은 장소 방문을 위한 파일럿이며, 실제 제휴 혜택을 운영할 때는 현장 QR·직원 확인 등 별도 증빙과 운영 정책이 필요하다. 현재 JSON 저장소는 단일 Node 서버의 개발·심사용 구성이다. 다중 서버 운영에는 공동 DB의 고유 제약과 트랜잭션으로 이전해야 한다.

## 보호센터

보호센터는 `봉사·커뮤니티` 안의 ‘유기견 보호센터’ 필터와 홈 바로가기로 찾는다. 방문·입양 상담·봉사는 센터별 신청·교육·연령·정원 조건을 확인하도록 안내하고 GPS 자동 적립에서 제외한다. 기관별 출처와 최신 확인의 한계는 [보호센터 자료 안내](ANIMAL_WELFARE_SOURCES.md)에 남긴다.

## 동작과 최적화

- GPS 적립 후와 MY 기록 재조회 후 완료 버튼을 비활성화한다.
- 상세 화면을 닫거나 다른 장소를 열면 이전 GPS 응답을 무시한다.
- 401 응답을 받으면 이전 사용자·잔액·쿠폰 상태를 비우고 다시 로그인하도록 안내한다.
- 로그인 자료의 늦은 응답이 로그아웃 후 다시 나타나지 않도록 요청 순서를 확인한다.
- 추가 라이브러리 없이 기존 24개 단위 서버 필터·페이지 나눔과 기존 카테고리를 사용한다. 로그인·AI 기능을 삭제하거나 보안 검사를 약화하지 않는다.

`npm run auth:test`는 제외된 활동 접근 거부, 익명 접근, 거리·정확도, 식당·축제별 적립액, 한국 시간 행사 기간, 같은 장소·동시 중복 요청, 보상액 위조, 계정 분리, 서버 재시작 후 적립 유지, 로그아웃을 확인한다. `scripts/verify-walkin-ui.mjs`는 PC·모바일 곳곳드림과 활동 둘러보기의 GPS 연결, 실제 로그인 후 적립·MY 재조회·늦은 GPS 응답·401 복구를 검증한다. 이 결과는 실제 제휴·기관 연동이나 Lighthouse 성능 점수를 보장하지 않는다.
