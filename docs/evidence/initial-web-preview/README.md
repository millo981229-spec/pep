# 첫 웹 미리보기 검증 기록

이 자료는 서버에 연결되지 않은 단일 HTML 웹 미리보기의 화면·상호작용 검증이다. 심사표의 23개 항목 점수나 실제 운영 준비 완료를 뜻하지 않는다.

- 대상: `/workspace/곳곳-웹-미리보기.html`. 정확한 파일 SHA-256과 실행 시각은 [검증 결과](browser-verification.json)에 기록했다.
- 환경: Chromium, 390px·1280px, 높이 900px, 인터넷 연결을 끈 브라우저 컨텍스트.
- 방법: 관리 환경의 브라우저 정책이 `file://` 이동을 차단하여, 동일 HTML 내용을 Playwright `setContent`로 직접 로드했다. 사용자의 실제 브라우저 파일 열기 동작까지 검증한 것은 아니다.
- 화면 검사: 홈·탐색·지도·AI 추천·교환소·마이, 총 12개 화면에서 문서 가로 넘침과 화면 밖으로 벗어난 본문 요소가 없었다.
- 동작 검사: 분야별 필터, 검색 빈 결과·조건 초기화, 상세 모달·Escape 닫기, 17개 시도 선택과 소개 변경, AI 추천의 로그인 유도, 미리보기 혜택의 교환 비활성화, 마이 화면의 로그인 안내를 두 화면 크기에서 확인했다. JavaScript 오류는 없었다.
- 미검증: 실제 로그인·이메일 인증·DB 저장·다른 계정 접근 차단·AI 제공자 호출·마일리지 적립 및 쿠폰 발급·배포 주소·Lighthouse 성능. 미리보기의 로그인 안내는 실제 인증 검증을 대신하지 않는다.
