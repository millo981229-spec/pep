# 전국 소지역 장소와 지도 연결 점검

2026-10-30 KST. 기존 204개에 음식점 233개와 명소 68개를 더해 총 505개를 제공한다. 현재 사이트의 17개 탐색 지역 아래 230개 시·군·구 선택 항목마다 지도 검색 가능한 서로 다른 장소가 최소 2곳 있다. 이 숫자는 사이트 탐색 목록의 수이며 최신 법정 행정구역 총수에 대한 주장이 아니다.

장소별 원본 주소, 고유 장소명, 지도 검색어, 좌표 확보 여부와 출처는 [locations.csv](locations.csv)에, 지역별 수는 [coverage.json](coverage.json)에 기록했다. `node scripts/audit-place-locations.mjs --write-evidence`로 재생성한다.

- 공개 수집본의 주소·좌표와 연결: 305개. 음식점은 기존에 사용한 공개 목록의 동일 ID, 나머지 좌표는 TourAPI 공개 수집본에서 대조했다. 현재 영업 여부나 네이버 검색 결과를 확인했다는 의미는 아니다.
- 지역과 고유 장소명으로 지도 검색: 198개. 정확한 도로번호·좌표·네이버 place ID를 추측하지 않았다. 최신 위치·개방·운영 확인은 남아 있다.
- 위치 보류: 2개. 누들대전축제는 원본 주소·좌표가 대전 중구이고 행사장 설명은 유성구 한빛탑광장이어서 충돌한다. 전주 시민축구단 항목은 확정 경기장 대신 공지 확인 문장이 주소로 들어 있었다. 두 항목은 지도 버튼을 막았고, 누들대전축제는 GPS 적립 대상에서도 제외했다.
- 네이버 지도 직접 확인: **0개**. `map.naver.com`은 환경 네트워크 정책에서 CONNECT 403으로 차단되었다. 검색 URL 생성·형식 검사·원자료 대조를 네이버 지도 확인 완료로 취급하지 않았다. 원래 사용하던 주소 검색을 실제 장소명+지역 검색으로 정리했지만 실제 검색 결과·네이버 place ID 연결은 추가 확인이 필요하다.

추가 음식점 원본: [공개 음식점 목록 고정 스냅샷](https://github.com/khh180cm/baekbangihaeng-map/blob/6648f79a316d7938cb6819c64e1271ba9ea9797f/public/data/restaurants.json). 가게명·주소·좌표만 대조했으며 외부 사진·리뷰·평점을 복사하지 않았다. 새 명소 중 수집본 좌표를 확보하지 못한 곳은 지자체·기관 안내 링크를 보존한 `link-only` 항목이다. 확인하지 못한 도로명 주소·좌표·영업시간·요금을 만들지 않았다.
