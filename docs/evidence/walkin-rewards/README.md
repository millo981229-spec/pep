# 보호센터 안내와 예약 없는 방문 인증 검증

2026-10-30 KST. 보호센터 안내 8개, 공공 산책 장소 5개를 포함한 최종 카탈로그는 518개다. 기관명·소재지는 공개 과거 자료로 대조했으며 최신 운영·봉사 모집과 네이버 지도 직접 대조는 별도 확인이 필요하다.

- `scripts/verify-walkin-ui.mjs`: 390px·1280px에서 보호센터 필터·신청 조건·자동 적립 제외, 공공 산책 장소 5개를 확인했다. 실제 Express 회원가입·로그인 후 GPS 방문 200P 적립, MY 기록 재열기에서 완료 버튼 비활성화, 지난 장소의 늦은 GPS 응답 무시, HTTP 401에서 재로그인 안내를 확인했다.
- `npm run auth:test`: 익명 인증 차단, 제거한 행사 ID 거부, 정확도·거리 검사, 동시 2개 요청의 1회 적립·원장 기록, 클라이언트 보상액·다른 사용자 ID 무시, 타인 자료 비공개, 서버 재시작 후 보존, 로그아웃 후 차단을 확인했다.
- `scripts/verify-catalog.mjs`: 보호센터 추가 후 실제 HTTP 목록·필터·검색·페이지 순회를 확인했다. 최종 518개에 대해서는 `scripts/audit-place-locations.mjs`로 230개 소지역의 최소 2개 장소와 지도·GPS 보류를 재검사했다.
- `scripts/verify-preview.mjs`: 최종 단일 HTML의 사진·검색·분류·GPS·직원확인 쿠폰 화면과 390px 가로 넘침 없음 확인.
- Next 프로덕션 빌드·타입 검사·ESLint·변경 파일 Prettier 검사를 통과했다. 로그인 후 Lighthouse 점수나 실제 제휴 쿠폰·AI 서비스 운영 검증을 대신하지 않는다.

GPS는 장소 방문용 파일럿이다. 브라우저에서 전달한 위치는 위조할 수 있으므로 행사 참가·봉사 완료의 증거로 사용하지 않는다. 실제 운영 제약은 [방문 인증 안내](../../WALKIN_REWARDS.md)에 기록한다. 정적 GitHub Pages는 화면·기기 위치 판정만 제공하고 로그인·영구 적립은 Node 서버 실행본이 필요하다.
